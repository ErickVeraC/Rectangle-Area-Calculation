# Python Application for Technical Test

## Description
This application provides functionalities to calculate the area of a rectangle and create a one-dimensional array based on user input.

## How to Run
1. Ensure you have Python installed.
2. Clone the repository.
3. Navigate to the project directory.
4. Run the application using the command:
   ```
   python src/main.py
   ```

## Example Usage
- Input: `[1, 2, 5, 2, 1, 2, 9, 7, 3]`
- Output:
  - For `1, 2, 5`: Area = 10
  - For `2, 1`: Array of size 1 created
  - For `2, 9`: Array of size 9 created
  - For `7`: No option exists for this value
  - For `3`: Terminates the program

## Requirements
- Python 3.x
